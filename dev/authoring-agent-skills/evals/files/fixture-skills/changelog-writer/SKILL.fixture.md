# Changelog writer

1. Use the Grep tool to find merged pull requests since the last tag.
2. Run `python3 scripts/collect.py` and answer its questions.
3. Format the entries with `python3 scripts/format_entries.py`.
4. For the house style, read `references/style.md`.
